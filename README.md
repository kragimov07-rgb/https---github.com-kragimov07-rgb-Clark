# RepairCalc — микросервис умных калькуляторов ремонта

SpbTechRun 2026 · кейс №1 «Микросервис умных калькуляторов ремонта и стоимости работ» (Максидом).

Пользователь выбирает объект, тип ремонта и помещения и получает смету: какие товары реального каталога
Максидома купить, сколько и за сколько, с учётом специфики комнаты (влажность, назначение, нагрузка).
В карточке товара сервис считает количество под размеры стены или комнаты и добавляет всё, что нужно для работы.
ML-модель сама относит 86 тыс. товаров каталога к 26 видам ремонтных работ — тысячи SKU не нужно размечать вручную.

## Результаты

| | |
|---|---|
| Каталог | реальный каталог Максидома: 88 790 товаров + YML-фид СПб (цены, наличие, дерево категорий) |
| ML-матчинг, новые товары | **micro-F1 0,966–0,974** (цель ≥ 0,8), nDCG@10 0,995–1,0 |
| ML-матчинг, незнакомые категории | micro-F1 **0,781** (baseline 0,723), macro-F1 0,625 (baseline 0,510) |
| Товары вне ремонта | 95–99% верно не получают видов работ |
| Расчёт количества | MAE = 0 на 16 эталонных расчётах, выполненных вручную |
| Производительность | смета на помещение 60–150 мс, разметка товара 2 мс, старт сервиса 12 с |

Подробно: [docs/methodology.md](docs/methodology.md), отчёт [reports/metrics_real.md](reports/metrics_real.md).

## Запуск с нуля

```bash
make setup                         # venv + зависимости
make model                         # модель эмбеддингов multilingual-e5-small в models/hf (один раз, ~470 МБ)

# данные организаторов (в репозиторий не входят):
#   data/real/raw/products_final.json        — Яндекс Диск из вики хакатона
#   data/real/raw/export_yandex_spb.xml      — https://fidsout.maxidom.ru/fids/export_yandex_spb.xml
python -m scripts.build_real_catalog          # каталог + фид -> data/real (≈ 8 с)

make train                         # обучение модели -> models/real (≈ 8–20 мин на M1 Pro; первый раз + эмбеддинги ≈ 10 мин)
make run                           # http://localhost:8000  (UI: /ui/, Swagger: /docs); первый старт ≈ 3 мин, далее 12 с
make test                          # 31 тест: эталонные расчёты, разбор характеристик, API
python -m eval.evaluate --folds 3 --no-ablation   # оценка на реальном каталоге (≈ 1 ч)
```

Синтетический каталог (без данных организаторов, за минуту): `RC_DATASET=synthetic make data train run`.
Локальная LLM (необязательно): `ollama pull qwen2.5:7b-instruct` — сервис сам начнёт использовать её для пояснений
и разбора текста. Развёртывание с GPU — `docker compose up -d` ([docker-compose.yml](docker-compose.yml)).

## Демо-сценарий для защиты

1. **«Смета»** → «квартира → капремонт → санузел 6 м², высокая влажность». Реальные товары Максидома:
   влагостойкий ГКЛВ KNAUF, полимерцементная гидроизоляция с заведением на стены, плитка с запасом на подрезку,
   клей и затирка по расходу из карточек, розетки IP44, вентилятор с обратным клапаном, тёплый пол, смесители,
   унитаз; формула у каждой позиции; пояснение «почему эти материалы».
2. **«Карточка товара»** → плитка → ширина и высота стены → упаковки, цена и сопутствующие товары
   «в корзину» (клей, затирка, грунт). Тот же расчёт — виджетом в [примере страницы магазина](static/product.html).
3. **«Админка»** → «Взять реальный товар, которого модель не видела» → ML предлагает виды работ, класс материала,
   помещения и похожие товары. «Синхронизировать» — 500 новых товаров со стенда загружаются и размечаются за ~3 с.
4. **«Качество ML»** → метрики по трём протоколам, F1 по каждому виду работ.

Презентация: [docs/RepairCalc.pptx](docs/RepairCalc.pptx) (заметки докладчика внутри; пересобирается командой
`python -m scripts.make_presentation`).

## Структура

```
app/            сервис: API, каталог, ML, расчёт, подбор, RAG, мок стенда
  ml/           матчинг (matcher.py), признаки (features.py), эмбеддинги, датасет
  calc/         план работ по помещениям, формулы расхода, сборка сметы
static/         UI (без сборки и CDN), виджет для карточки товара
data/           справочник видов работ, база знаний, эталон реального каталога, синтетический каталог
scripts/        сборка реального каталога и эталона, обучение, загрузка со стенда, скриншоты, презентация, лицензии
eval/           оценка качества, согласованность разметчиков
docs/           таксономия, реальные данные, методика, архитектура, презентация, лицензии
tests/          эталонные расчёты (MAE = 0), разбор реальных характеристик, API
```
