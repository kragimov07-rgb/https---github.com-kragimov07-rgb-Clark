# Справочник видов ремонтно-отделочных работ RepairCalc

Версия 1.0 · машиночитаемая версия: [data/taxonomy.yaml](../data/taxonomy.yaml)

## 1. Принципы построения

1. **Технологическая последовательность ремонта.** Виды работ сгруппированы по этапам: подготовка → черновые
   работы → инженерные системы → чистовая отделка → завершающие работы. Так устроены реальные сметы и
   технологические карты, поэтому справочник напрямую используется калькулятором для построения плана работ.
2. **Вид работ = законченная технологическая операция**, которую выполняет один специалист одним набором
   материалов и инструмента («укладка плитки», «монтаж гипсокартона»). Мы не дробим операцию на подоперации
   («нанесение клея», «затирка швов») — это материалы одной работы — и не укрупняем до этапов («черновая отделка»).
3. **Полнота охвата.** 26 видов работ покрывают типовой ремонт квартиры, студии и дома изнутри: все поверхности
   (пол, стены, потолок), инженерные системы (электрика, сантехника, отопление, вентиляция), проёмы (двери, окна).
   Сознательно вне охвата: строительство стен (кладка блоков), фасады, кровля, фундаменты, садовые работы —
   товары этих групп размечаются как «не относится к ремонту помещений».
4. **Практическая применимость.** Каждому виду работ соответствует набор классов материалов и формул расхода
   в калькуляторе ([app/calc/plan.py](../app/calc/plan.py)), т.е. разметка «товар → вид работ» сразу используется
   для подбора товаров в смету и сопутствующих товаров в карточке.
5. **Расширяемость.** Новый вид работ добавляется записью в `taxonomy.yaml` (код, название, этап, описание с
   типовыми материалами). Описание используется zero-shot компонентом модели, поэтому новый вид работ начинает
   распознаваться ещё до появления размеченных примеров.

## 3. Правила разметки «товар → вид работ»

Задача многометочная: товар относится ко **всем** видам работ, в которых он применяется по стандартной технологии.

| № | Правило | Пример |
|---|---|---|
| R1 | Товар относится к виду работ, если он является **основным материалом**, **расходным материалом** или **специализированным инструментом** этой работы по стандартной технологии. | Плиточный клей → укладка плитки |
| R2 | Если товар штатно применяется в нескольких работах — ставятся **все** такие метки. | Грунтовка глубокого проникновения → грунтование, покраска, обои, плитка, шпаклевание, штукатурка |
| R3 | Метка ставится по **назначению товара**, а не по совпадению слов в названии. | «Перфоратор для обоев (тигр)» → демонтаж, поклейка обоев (это не электроинструмент) |
| R4 | Универсальный инструмент (уровень, миксер, ведро) получает метки работ, в которых он **обязателен по технологии**, а не всех работ подряд. | Уровень → плитка, ГКЛ, штукатурка, стяжка, двери, панели, потолки, ламинат; не обои и не покраска |
| R5 | Средства индивидуальной защиты, бытовые и садовые товары, товары для строительства (кладка, фасад, кровля) — **без меток** (вне ремонта помещений). | Перчатки, шланг, мангал, клей для газобетона, фасадная краска |
| R6 | Характеристики, которых нет в карточке, не домысливаются из маркетингового описания (требование кейса). При неясности — метка по категории каталога и названию. | — |
| R7 | Неоднозначные товары размечаются по **основному назначению** + всем штатным дополнительным. | Клей для стеклохолста → покраска (стеклохолст под покраску) + обои |

### Разбор неоднозначных случаев (включены в тестовый набор)

| Товар | Метки | Почему |
|---|---|---|
| Обои под покраску | поклейка обоев, покраска | клеятся как обои, затем окрашиваются |
| Шпаклёвка финишная | шпаклевание, покраска | финишный слой — подготовка именно под окраску |
| Монтажная пена | двери, подоконники и откосы, герметизация | штатный материал монтажа дверей и окон |
| Санитарный герметик | герметизация, сантехника | швы ванн, раковин, поддонов |
| Полотенцесушитель | сантехника, отопление | подключение к ГВС/отоплению или электросети |
| Подвес прямой | ГКЛ, потолки | каркас для обшивки и подвесных потолков |
| Дюбель-гвоздь | ГКЛ, плинтусы, электромонтаж, панели | крепление профиля, плинтуса, кабель-канала, обрешётки |
| Клей для газобетона | — | кладка стен — вне охвата ремонта помещений |
| Краска фасадная | — | наружные работы — вне охвата |
| Ковёр комнатный | — | текстиль интерьера, а не напольное покрытие (в отличие от ковролина) |

## 4. Второй уровень: класс материала

Для расчёта количества каждому товару дополнительно присваивается класс материала (48 классов: `tile`,
`tile_adhesive`, `grout`, `primer`, `paint`, `wallpaper`, `laminate`, `drywall_sheet`, `cable`, …,
`tool`, `other`). По классу калькулятор выбирает формулу расхода и единицу расчёта (площадь, длина,
электроточки, штуки). Класс тоже предсказывается ML-моделью.

## 5. Специфика помещений

| Помещение | Влажность | Нагрузка | Ограничения при подборе |
|---|---|---|---|
| Санузел, ванная | высокая | средняя | только влагостойкие материалы (ГКЛВ, плитка, IP44), гидроизоляция, вентиляция |
| Туалет | средняя | средняя | влагостойкие материалы, гидроизоляция пола |
| Кухня | средняя | высокая | моющиеся покрытия стен, износостойкий / водостойкий пол (≥ 33 класс) |
| Детская | низкая | высокая | экологичные (E1) и моющиеся материалы, пол ≥ 33 класс |
| Прихожая | низкая | высокая | износостойкий пол, моющиеся стены |
| Гостиная, спальня | низкая | средняя/низкая | без ограничений, пол ≥ 32 класс |
| Балкон, лоджия | средняя | низкая | морозостойкие материалы, утепление |
