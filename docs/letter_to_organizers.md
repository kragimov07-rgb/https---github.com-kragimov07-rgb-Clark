**1. Справочник видов работ (собственная таксономия).**
26 видов работ в 5 этапах по технологической последовательности ремонта: подготовка → черновые → инженерные
системы → чистовая отделка → завершающие. Справочник, принципы классификации, правила сопоставления
(R1–R7) и разбор неоднозначных случаев — во вложении `taxonomy.md`.

**2. Постановка задачи.** Многометочная классификация «товар → виды работ»: один товар может относиться
к нескольким видам работ. Товары вне ремонта помещений (сад, быт, кладка, фасад) получают пустой набор меток.

**3. Тестовая выборка.** Каталог из 1 140 карточек в формате API стенда (124 подтипа товаров, 23% товаров
с несколькими видами работ, 7% вне ремонта, специально добавлены неоднозначные товары). Эталон размечен по правилам
справочника. Образец из 248 товаров независимо перепроверяют два участника команды, считаем каппу Коэна.
Отдельно лежит выгрузка «новых товаров», которые не участвуют в обучении.

**4. Метрики.** Основная — micro-F1 (цель ≥ 0,8). Дополнительные: macro-F1, nDCG@10 и MAP (качество ранжирования
товаров внутри вида работ), доля верно распознанных товаров вне ремонта, F1 на товарах с несколькими метками.

**5. Протоколы проверки.** Три протокола:
- 5-fold по товарам;
- 5-fold по подтипам товаров: в тесте только те виды товаров, которых модель не видела;
- отдельная выгрузка новых товаров.

Всё воспроизводится одной командой `make eval`, отчёт сохраняется в `reports/metrics_synthetic.md`.
